TSP 三角距離配列・経路ビジュアライザ

正N角形に都市1〜Nを時計回りに配置。完全グラフの辺は描画しません。

1. N と seed

「距離配列を生成」を押すと、seedで決まる大きさの正N角形を生成し、全都市間距離を三角配列で表示します。都市の配置は常に正多角形です。

2. N と距離の三角配列

1行目：N個（d(1,1)〜d(1,N)）、2行目：N−1個（d(2,2)〜d(2,N)）、…、最終行：1個（d(N,N)）。距離は非負の数、対角成分は0。手入力・貼り付けして「配列を反映」もできます。

距離配列を生成するか、貼り付けてください。

3. 訪問順の配列

都市1から出発し、2〜Nを各1回訪問して都市1に帰着。カンマ・空白区切り、[]の有無は自由です。

訪問順が正しく入力されるまで経路は描画しません。

4. ビジュアライザ

都市を正N角形の頂点に時計回りに配置します。灰色の円は位置の目安で、完全グラフの辺は表示しません。有効な経路を入力したときだけ進行方向を示す青い矢印を描画します。スコアは三角配列の値の合計です（小さいほど良い）。各区間と合計の移動時間も下に表示します。

※ 三角配列の数値をその区間の移動時間（時間単位）として扱います。距離を時間へ変換する速度設定はありません。図は都市の順序と経路を示します。
