TSP Route Visualizer

seedで都市を生成・巡回順を検証・経路長を採点

1. 問題設定

都市は 0, 1, ..., N-1。同じN・seedなら同じ座標になります。Nは2〜300。

2. 訪問順の入力

カンマ、空白、改行で区切れます。角括弧 [ ] も使用可能です。都市0を出発・帰着地点とします。
まだ経路は描画していません。正しい訪問順を入力してください。

3. ビジュアライザ

正しい長さ N+1 の配列が入力されたときだけ
訪問経路を表示します。
完全グラフの辺は描画しません。
青線：訪問順に沿った経路 ／ 緑：出発・帰着都市 0 ／ 数字：都市番号。スコアは各辺のユークリッド距離の合計（小さいほど良い）。
GitHub Pagesで動作する静的サイトです。サーバー不要・外部ライブラリ不要。
